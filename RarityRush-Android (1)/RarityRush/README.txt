RARITY RUSH - ANDROID PROJECT
=============================
1. Install Android Studio (free): https://developer.android.com/studio
2. File > Open, and pick this RarityRush folder. Let it sync (accept any
   prompts to install SDK pieces or create the Gradle wrapper).
3. Plug in your phone (USB debugging on) or start an emulator, then press Run.
4. To get an APK to share: Build > Build Bundle(s) / APK(s) > Build APK(s).

The game itself lives in app/src/main/assets/index.html. Replace that file
with a newer version of the game any time and rebuild.
Progress is saved on the device. Nothing needs the internet.

NO ANDROID STUDIO? BUILD THE APK ONLINE FOR FREE
================================================
1. Make a free GitHub account and create a new repository.
2. Upload everything in this folder (including the hidden .github folder).
3. Open the Actions tab > "Build APK" > wait for the green check.
4. Open that run and download the RarityRush-APK file at the bottom.
5. Unzip it, send app-debug.apk to your phone, and install it
   (Android will ask you to allow installing from unknown sources).
